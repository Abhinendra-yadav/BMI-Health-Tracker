# 📊 BMI Health Tracker

A complete Full-Stack web application that allows users to calculate their Body Mass Index (BMI), find out their health category, and maintain a detailed history of their past records. 

## 🚀 Features
- **Accurate BMI Calculation:** Instantly calculates BMI based on weight (kg) and height (cm).
- **Database Integration:** Securely saves user data, calculated results, and health categories.
- **History Tracking:** Dedicated history page to view all past BMI records with timestamps.
- **Responsive UI:** Clean, modern, and user-friendly interface.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** Java (Servlets, JDBC)
- **Server:** Apache Tomcat 9.0
- **Database:** MySQL
